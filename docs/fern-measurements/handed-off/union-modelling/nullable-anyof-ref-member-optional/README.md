## The rule

A component `anyOf`/`oneOf` of two or more members written with a 3.0 `nullable: true` beside it is the plain union: the schema-level `nullable` is not read onto the alias. A member that names a component which itself admits `null` (`nullable: true`, or a `type: null` member) is that component made `Optional` in its own slot.
