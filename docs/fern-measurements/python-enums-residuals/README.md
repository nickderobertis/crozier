# `python_enums` residuals of two literals-proven shapes

Two scenario shapes of the
[scenario proof index](../../openapi-surface/scenario-proof-index.tsv) are
defined under Fern's default `enum_type` (literals) and proven there alone, by
their complete literals trees in [`../literals-mode/`](../literals-mode/README.md)
(`literals_mode_measurements_match_fern`). Each was measured again under
`pydantic_config.enum_type: python_enums`, crozier's default, over the same
committed document, with Fern CLI **5.67.1** and `fernapi/fern-python-sdk`
**5.20.0**. The scaffold is the one `tools/fern-goldens/generate-fern-fixture.sh`
writes (organization `fern`, packaged layout), and the comparison is
`crozier compare` with package `fern` and project `default_package_name`.
Neither result counts toward `python_enums` parity.

## `enum-header-params-stringified`: differs

Document: [`../literals-mode/enum-header-params-stringified/openapi.yml`](../literals-mode/enum-header-params-stringified/openapi.yml).

Of 41 files compared, one differs: `src/fern/trams/raw_client.py`. Fern sends
each `$ref` string-enum header as `shift.value` and `traction.value`. crozier
sends `str(shift)` and `str(traction)`. The difference is at reference lines
51-52 and 132-133, in the sync and async methods. A `StrEnum`'s `str()` is its
value, so the wire bytes agree, but the generated bytes do not. No departure
covers this difference. It is an open generator residual with no owning
scenario in this plan, and it has no unmatched allowance anywhere. The complete
normalized comparison is
[`enum-header-params-stringified.diff`](enum-header-params-stringified.diff).

## `enum-extension-names-dropped-under-literals`: matches

Document: [`../literals-mode/enum-extension-names-dropped-under-literals/openapi.yml`](../literals-mode/enum-extension-names-dropped-under-literals/openapi.yml).

All 40 files compared are equal, with only the catalogued
`sdk-identity-header-prefix` branding departure applied. The earlier `python_enums`
difference, Fern's `x-fern-enum` member docstrings, no longer reproduces on the
finished tree. No `python_enums` golden of this document is committed or gated,
so the match is a measurement, not a proof.
