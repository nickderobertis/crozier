# union-body-item-example

A required model field typed as a union whose first member is itself a union admitting `null` has no sample in the certified pair. Where the model is the first member of a list item union, its Markdown shows the list empty (`items=[]`), which crozier now writes. Its docstring constructs the model without the required field, which raises a `ValidationError` when run, so crozier keeps the field under the `required-null-union-field-example` departure.

Verdict: `fern-defect-departed` for the docstring; the Markdown rule is repaired.
