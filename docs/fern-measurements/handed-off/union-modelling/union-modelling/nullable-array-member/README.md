## The rule

A union member written `{type: array, items: …, nullable: true}` is `Optional[List[…]]` in its own slot, exactly as a nullable scalar member is `Optional[…]`.

## The comparison

The certified pair declares `Tag = typing.Union[typing.Optional[str], typing.Optional[int], typing.Optional[typing.List[str]]]`; crozier wrapped only the scalar members and wrote `typing.List[str]` for the array (langfuse's `MapValue`). Repaired in `Builder::variant_ref`; crozier now byte-matches `fern-expected/`.
