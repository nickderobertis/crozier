## The rule

An inline object alternative of a query parameter's `oneOf`/`anyOf` that declares its structure — properties, or a declared empty `properties: {}` closed by `additionalProperties: false` — is a model of its own, named as a body union's variant is (`{Union}{Distinguishing property}`, else its ordinal) and declared beside the union alias that lists it. The certified pair declares:

- `glaze` (`anyOf: [string, closed empty object]`): `ListFiringsRequestGlaze = typing.Union[str, ListFiringsRequestGlazeOne]`, with the empty model `ListFiringsRequestGlazeOne`, in the package root's `types/` with its alias;
- `kiln_id` (`nullable`, `anyOf: [string, closed {any, all}, string array]`): `typing.Union[str, ListFiringsRequestKilnIdAll, typing.List[str]]`, the model named by `all`, its alphabetically first own property, in `firings/types/`;
- `cone` (required, `oneOf: [integer, open {low, high}]`): `typing.Union[int, ListFiringsRequestConeHigh]`.
