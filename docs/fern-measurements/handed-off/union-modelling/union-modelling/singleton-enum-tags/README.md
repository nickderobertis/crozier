## The rule

A union whose members each tag one property with a typed one-member `enum` is discriminated on it, whether a member is a `$ref` requiring the tag or an inline object leaving it unrequired; the `$ref`ed models lose the tag field. (A `$ref` whose tag is unrequired still does not discriminate beside inline members.)

## The comparison

The certified pair writes `Author` as the `kind`-discriminated union `Author_Crew`, `Author_Contractor`, `Author_Autopilot`, `Author_Harbour`, and `CrewMember`/`Contractor` without `kind`. crozier wrote the inline members `AuthorTwo`/`AuthorThree` in a plain union and kept `kind` on both models (ironclad's `ActivityAuthorModel`). Repaired in `inferred_discriminant_property` (which `inferred_strip_discriminant_property` now shares). crozier now byte-matches `fern-expected/`.
