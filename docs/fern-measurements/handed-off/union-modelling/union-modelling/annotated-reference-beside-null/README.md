## The rule

A property `anyOf: [allOf: [$ref Target, annotation], null]` is the use-site copy the bare annotated `$ref` is: an object target restated under `{Owner}{Prop}`, an enum target copied as an enum, a map target the nullable map, a lone unmapped `$ref` target that reference.
