## The rule

A property `oneOf` of two or more `$ref`s under a `discriminator` that names only `propertyName`, whose members' tags do not tell them apart (each allows several values), is an ordinary union named for the property, `{Owner}{Prop}`; a model inheriting the property through `allOf` reuses that name.
