## The rule

A component that is an `allOf` of an open object declaring no properties (`properties: {}`, `additionalProperties` open) and one `oneOf` or `anyOf` of inline objects is one model of every branch's properties, all optional, each property written as the *first* branch declaring it writes it: its schema, `const` or one-member `enum` tag (hoisted as a one-value enum, `HandoverOneOfConstMode`) and description alike, whether or not the branches tag themselves. The document probes all four of `oneOf`/`anyOf` × `const`/`enum`; every one is the first branch's.
