# `sdk-identity-header-prefix`

**Kind:** `branding`. crozier names its own SDK-identity headers.

## The command and its result

Over the committed `alma-france` corpus document, with the corpus's settings:

```text
$ spec=$(python3 tools/corpus/corpus_sources.py prepare --fixture alma-france --output /tmp/alma-src)
$ crozier generate --spec "$spec" --output /tmp/alma --package-name fern --project-name default_package_name
$ diff tests/fixtures/alma-france/expected/src/fern/core/client_wrapper.py /tmp/alma/src/fern/core/client_wrapper.py
1c1
<
---
> # This file was auto-generated by crozier from an OpenAPI document.
36,40c36,40
<             "X-Fern-Language": "Python",
<             "X-Fern-Runtime": f"python/{platform.python_version()}",
<             "X-Fern-Platform": f"{platform.system().lower()}/{platform.release()}",
<             "X-Fern-SDK-Name": "default_package_name",
<             "X-Fern-SDK-Version": "0.0.0",
---
>             "X-Crozier-Language": "Python",
>             "X-Crozier-Runtime": f"python/{platform.python_version()}",
>             "X-Crozier-Platform": f"{platform.system().lower()}/{platform.release()}",
>             "X-Crozier-SDK-Name": "default_package_name",
>             "X-Crozier-SDK-Version": "0.0.0",
```

The first difference is a comment, outside the comparison. Each of the other
five is this departure: the same header with the same value, named
`X-Crozier-` instead of `X-Fern-` (the emitter writes them in
`src/emit.rs`, where the client wrapper's `get_headers` is built). The flat
layout writes the first three only, on both sides.

Every golden's client wrapper carries these lines, so every golden's rows in
`tests/fixtures/departures-ledger.tsv` include them.
