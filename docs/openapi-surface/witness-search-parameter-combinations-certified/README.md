## Differences repaired here

- **Query union object members (ticket #815).** A query `oneOf`/`anyOf`'s inline
  object alternative is a named model, as a body union's variant is
  ([measurement](../../fern-measurements/handed-off/union-modelling/query-union-object-members/README.md)).
- **A required query object's types stay in its tag's `types/`**, exactly when
  requiredness differs from nullability, as a query union's do (corpus row 6101).
- **A referenced urlencoded body reuses its component's inline object type**
  (`ProductOrderAddress`) instead of declaring an operation-scoped copy (corpus row 6101).
