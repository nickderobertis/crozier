# Schema combination bounded search

This node re-read the registered corpus sources, the pinned APIs.guru archive,
the earlier acquired bytes retained by the guarded response cache, and the
handed-off documents. A positive declaration is a candidate, never interaction
proof. The bound is these retained populations and the recorded instrumented
controls and certified comparisons; no live code search was used. Missing bytes
and unfinished arm-specific comparisons remain outstanding. No fallback search
is exhausted.

## Open proof obstructions

The [union measurements](../combination-open-unions/README.md) record the full
failed union laws for combo-allof-schema-example and
combo-annotated-ref-property-example, source quotes and exact differing regions.
Neither is independent.

For combo-allof-nullable-member, combo-map-of-nullable-values,
combo-property-ref-to-nullable-target and combo-property-ref-to-read-only-target,
the nested/target selector entails the containing composition, map or reference
selector. A document with the nested feature alone cannot exist under the
selector grammar. Valid controls are the containing feature alone and both.
These rows remain open until a dedicated conjunctive region and a registered
certified witness are established. No impossible control is invented and none
is classed independent.

Other open rows need a registered specification executing their interaction arm
and byte-matching, or an exhausted search admitting a hand-written fallback.
The outstanding TSV names every candidate and reason; it is not a claim that
every candidate was screened.
