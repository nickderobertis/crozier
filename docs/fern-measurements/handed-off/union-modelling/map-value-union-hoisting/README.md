# map-value-union-hoisting

**Verdict: user-ruling (ruling 6, `inline-union-types`)** (row `map-value-union-hoisting` of [`../union-modelling.tsv`](../union-modelling.tsv)).

`openapi.yml` was authored from scratch for this rule. `fern-expected/` is Fern CLI 5.163.1 with `fernapi/fern-python-sdk` 5.41.3's complete, comment-stripped output for it, generated by `tools/fern-goldens/fern-references.py generate measurements` for the `docs/fern-measurements/cases.tsv` case `handed-off/union-modelling/map-value-union-hoisting`, under the shared Fern lock. The enum mode changes nothing here but `core/enum.py` and `.fern/metadata.json`, so no `literals/` tree is committed.

## The rule

A component map whose `additionalProperties` is an `allOf` of one `$ref` and nothing else has that reference as its value type (made `Optional` where the target admits `null`), with no value model of crozier's own. A map nested as the leaf of an array of arrays, whose values are inline objects, names that value model `{Name}ItemItemValue` (and its own nested models beneath it).

## The comparison

The certified pair writes `DepthsByStation = typing.Dict[str, Depth]`, `BuoysByStation = typing.Dict[str, typing.Optional[Buoy]]`, `SoundingsByStation = typing.Dict[str, SoundingsByStationValue]` and `TideGrid = typing.List[typing.List[typing.Dict[str, TideGridItemItemValue]]]`. crozier hoisted `DepthsByStationValue` and `BuoysByStationValue` models of its own and typed the `TideGrid` leaf `typing.Dict[str, typing.Any]`. Under ruling 6 (`inline-union-types`) crozier writes the certified pair's types: it now byte-matches.

Held by `map_values_take_the_certified_pairs_types_rather_than_hoisted_value_models` in `crates/crozier-e2e/tests/e2e/union_modelling.rs`: crozier generates `openapi.yml` and the SDK must byte-match `fern-expected/` (and `literals/fern-expected/` in `literals` mode where committed) apart from the catalogued departures the ledger records for the tree, and the pre-repair spelling written back into crozier's output must fail that comparison. The unit test `map_values_are_the_referenced_type_and_nested_map_leaves_name_their_value` in `src/ir.rs`'s `union_modelling_tests` drives the repaired lowering on the same document.
