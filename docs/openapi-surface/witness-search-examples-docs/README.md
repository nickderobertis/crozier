# Witness search for the examples and docs shapes

Eighteen shapes of crozier's worked examples, README, `reference.md` and
docstrings, each measured against the certified pair (Fern CLI 5.67.1,
`fernapi/fern-python-sdk` 5.20.0). Each needs a real specification whose
complete golden crozier byte-matches, or, failing one, a hand-written fixture
under [`../handwritten/`](../handwritten/AGENTS.md) whose cover cites the
verdict below. Every hand-written fixture here is also measured under Fern's
default `enum_type` (`literals`) in
[`../../fern-measurements/literals-mode/`](../../fern-measurements/literals-mode/README.md).

## The search

Two populations, each read by one detector per shape (below), run on
2026-10-10:

- **APIs.guru.** `APIs-guru/openapi-directory` at
  `f04b8d0bcd39c52e1cf3ad7a5fe744709832ae49`, the revision the corpus's
  `github-raw` APIs.guru rows already pin, read from that revision's archive
  as extracted for [`../witness-search-prove-matches/`](../witness-search-prove-matches/README.md#the-search);
  no network request was made. Every `.yaml`, `.yml` and `.json` file under
  `APIs/` was parsed with PyYAML 6.0.3's C loader; 1,927 OpenAPI 3.x documents
  were read and 48 files could not be parsed.
- **The registered corpus.** Every OpenAPI 3.x document under
  `tests/fixtures/` (each committed corpus source and each vendored fixture
  `openapi.*`): 266 documents.

[`census.tsv`](census.tsv) lists every document a detector counts for a key,
with its site count. A site declares the whole trigger the detector names.
GitHub code search, Sourcegraph, the vendor portals and the registries were
not queried for these keys, so no key is `exhausted`.

### How a declarer was screened

A declarer is admissible under [`../../corpus-licensing.md`](../../corpus-licensing.md)
through its own `info.license`, or, declaring none, through the aggregating
repository's own licence. Each admissible one was generated by the pinned Fern
pair and, where Fern generated, compared whole with crozier's output through
`crozier compare`. A registered declarer already carries a byte-matched
golden; it is a witness only when that golden shows the shape.

## The real witnesses

Two shapes have a real specification declaring the whole trigger, and need no
hand-written fixture.

| key | witness | golden | comparison test |
|---|---|---|---|
| `description-comment-close-not-split` | corpus row 2200, `googleapis-speech-v2beta1`: the operation listing's description names `users/*/operations`, written `users/* /operations` in `projects.speech_projects_locations_operations_list`'s sync and async docstrings, its raw clients and `reference.md` | `tests/fixtures/googleapis-speech-v2beta1/expected`, `tests/fixtures/googleapis-speech-v2beta1/expected-literals` | `googleapis_speech_v2beta1_matches_fern_output`, `overlay_goldens_match_fern_output` |
| `readme-omitted-without-demonstrable-endpoint` | corpus row 2201, `googleapis-youtubeanalytics-v1`: a document with no operation, whose flat tree has no `README.md` and whose packaged tree has an empty one | `tests/fixtures/googleapis-youtubeanalytics-v1/expected-flat`, `tests/fixtures/googleapis-youtubeanalytics-v1/expected` | `googleapis_youtubeanalytics_v1_flat_matches_fern`, `googleapis_youtubeanalytics_v1_matches_fern_output` |

Of the 144 APIs.guru declarers of `description-comment-close-not-split`, 124
carry an admissible licence; the smallest, `googleapis.com/speech/v2beta1`, was
generated first and byte-matched, and `googleapis.com/mybusinessqanda/v1`
matched too. Of the 13 declarers of a document with no operation, only
`googleapis.com/youtubeAnalytics/v1` grants redistribution. The registered
`atlassian.com-jira` and `github.com` declare `*/` descriptions but are refused
by Fern, and the ten registered documents with no operation carry no flat
golden, the only tree in which the shape shows.
