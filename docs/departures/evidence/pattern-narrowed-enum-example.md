# Pattern-narrowed enum example

The independently authored `measurement-phase` source intersects the `Phase`
string enum with `^(?!preparation$).*$`. The complete unedited certified trees
were generated by Fern CLI 5.67.1 and `fernapi/fern-python-sdk` 5.20.0. The
primary handwritten tree records `python_enums`; its complete companion under
`docs/fern-measurements/models-refs-literals` records the unset literals default.

The alias, field annotation and scalar-member description are matched output.
The fault is only the generated `preparation` example: the enum admits that
value, but the scalar pattern rejects it. `recording` is the first enum value
admitted by both members.

The executed validation below imports the certified package, extracts every
`phase` argument from its README, reference and client docstrings, and validates
the actual enum wire value or literal against the property's two members. It
expects rejection for every certified default and acceptance for `recording`.
No network request is made by the example calls. The comparison's source-aware
rule checks this same finite enumeration and pattern, at argument lines in
README, reference and client documentation only; absent source, different
arguments, altered annotations or another rejected replacement do not match.

Executed on 2026-10-08 with Python 3.14.7, jsonschema 4.26.0 and PyYAML 6.0.3:

```sh
python crates/crozier-e2e/tests/e2e/evidence/pattern-narrowed-enum-example.py docs/openapi-surface/handwritten/measurement-phase/fern-expected docs/openapi-surface/handwritten/measurement-phase/openapi.yml
python crates/crozier-e2e/tests/e2e/evidence/pattern-narrowed-enum-example.py docs/fern-measurements/models-refs-literals/measurement-phase/fern-expected docs/openapi-surface/handwritten/measurement-phase/openapi.yml
```

Both invocations reported:

```text

```

The validator is the committed script beside this note. Its eight observations
are the synchronous and asynchronous README examples, both endpoint reference
examples, and both endpoints’ synchronous and asynchronous client docstrings. The Python-enums
invocation reads each actual imported enum member's wire value; the literals
invocation reads each actual AST string argument.
