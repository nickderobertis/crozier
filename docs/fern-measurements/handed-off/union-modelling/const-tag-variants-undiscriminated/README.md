## The rule

A union of `$ref` members, each fixing an *unrequired* tag property with a bare `const` (no `type: string`), and written without a `discriminator`, is a plain `typing.Union` of the members; each member keeps the tag as a one-value enum (`SailboatHull`, an open `Literal` union in `literals` mode). This is the `const` side of one discriminant-inference rule whose one-member `enum` side is [`union-modelling/singleton-enum-tags`](../union-modelling/singleton-enum-tags/): a typed one-member `enum` discriminates, a bare `const` does not.
