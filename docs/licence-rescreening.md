# Screening the licence-blocked candidates against the widened rule

The corpus's admissible-licence rule widened
([`corpus-licensing.md`](corpus-licensing.md)), and every screening outcome
recorded under [`openapi-surface/`](openapi-surface/) was measured against the
narrower one. This file is the rescreening: **one line per document** the six
region files record as blocked on a licence, or as never screened because a
licence stopped it first, saying what the widened rule says about that document,
what Fern does with it, and which coverage rows it declares.

**This file reports; it does not register.** Adding a
[`CORPUS.md`](../tests/fixtures/CORPUS.md) row, saving a golden and reaching
parity is separate work, governed by
[`../tests/fixtures/AGENTS.md`](../tests/fixtures/AGENTS.md). What is settled
here is only which candidates are worth that work.

`just lint-licence-rescreening` holds the table below to the shape the
registering node reads it with — deriving the candidate set from the region
ledgers itself, so a grouped line or a dropped document fails — and
`just test-licence-rescreening` proves that gate still discriminates. Both are
in `just check`.

## Where the candidates came from

The six region files' `### Witness search (issue #188)` tables and the candidate
ledgers beneath them. That search read both complete document corpora whole — all
4,138 APIs.guru documents at `f04b8d0bcd39c52e1cf3ad7a5fe744709832ae49` and all
74,240 `jentic/jentic-public-apis` documents at
`eb9d12a2684b0fbcb5aecf51e8ae54dba0929743`, beside five further sources — and is
the authoritative one, so **no fresh world search was run here**.

The scope is derived rather than asserted. `scripts/licence-rescreening-check.py`
walks those tables and takes:

* every **candidate ledger row** whose licence cell or verdict cell names a
  licence among what blocks the candidate — and then **every document that row
  names**, so a row covering seven repositories or ten SwaggerHub versions is
  seven or ten candidates rather than one;
* every **witness row** whose outcome is `witness-blocked` and which records a
  licence rather than `—`.

Each derived document must be carried by exactly one line below, and each
in-scope row must be cited by at least one, so nothing can be hidden inside a
plural. A candidate a region file blocks on something else — a synthetic
fixture, a third-party transcription, a shape it turns out not to declare — is
not in that set; where such a document shares a row with a licence-blocked one
it is screened here anyway, and its line says what really stops it.

## The screening path

The same two-stage screen the region files' own searches ran, because this
repository's rejected ledger is full of documents that pass the first stage and
are refused by the second, and a whole class of failure exits zero having
generated an empty SDK. **Every candidate was put through it**, whatever its
licence verdict:

```bash
curl -sSL -o openapi.<ext> "<the fetch URL in the ref column>"
# scaffolded into a workspace: fern.config.json {"organization":"fern","version":"5.114.1"},
# generators.yml with api.path: openapi/openapi.<ext> and one generator,
#   fernapi/fern-python-sdk 5.20.0, pydantic_config.enum_type: python_enums
fern check
fern generate --group python-sdk --preview
```

That is the workspace [`../scripts/generate-fern-fixture.sh`](../scripts/generate-fern-fixture.sh)
builds, at the Fern CLI and generator versions the region files' searches record —
CLI **5.114.1**, `fernapi/fern-python-sdk` **5.20.0**, the version
`tests/fixtures/eos.local/expected/.crozier-fern-golden.json` pins. Every exit
status and diagnostic below is that run's own output on this host, quoted rather
than paraphrased, beside the byte count and MD5 of exactly what the fetch
returned. Declaration counts are re-measured out of those bytes with
`scripts/openapi-surface-census.py`'s own object model, not inherited.

Three references the world does not make immutable are screened all the same and
say so: a SwaggerHub version string is republishable in place, and Short.io
serves its document at a live address. Screening them is what turns "blocked on
two things" into a measured statement about both.

**Every `document check` and `generate` figure in the table below is that preview
path at CLI 5.114.1, and a preview-path exit 0 is not an acceptance.** Two things
separate the two, and both have bitten this corpus:

* **A Fern verdict is CLI-version-bound.** The corpus generates at the CLI
  [`../scripts/generate-fern-fixture.sh`](../scripts/generate-fern-fixture.sh)
  pins — `FERN_CLI_VERSION` **5.67.1**, the version every committed golden's
  `.fern/metadata.json` records — and a document this record admits can still be
  refused there. Eclipse Ditto is that case.
* **Fern exits 0 over a document it never parsed.** It logs the skip, prints
  `All checks passed`, and writes an empty SDK. CureDAO is that case, and it
  reaches exit 0 at *both* CLIs, so no version comparison reveals it — only
  reading what the generate wrote does.

So the two Fern columns record what a *command exited*, and the registering node
is what records whether Fern produced an SDK. **Every candidate below was screened
on the preview path only**, except the seven put to the corpus's own generation
path as well — the five registered as corpus rows 133-137, plus `eclipse-ditto`
and `curedao`, whose two paths disagree or whose exit status hides a skip. Those
seven carry that second measurement in their own `generate` cell.

## How to read a line

* **admission** is exactly `admitted` or `still-blocked` — whether
  [the rule](corpus-licensing.md) as it now stands reaches the document.
  `admitted` says the licence is no longer what stops it; it does not say the
  document is registrable, which the Fern columns and the corpus's own
  real-world and immutability rules decide.
* **source** is the region ledger row this line answers, as
  `<region>.md:<line>`. A document two rows name carries both citations.
* **pinned ref** is what was fetched: a commit or an immutable version
  reference, or `no immutable ref —` and why the world offers none, and in every
  case the URL, the byte count and the MD5 of what came back.
* **rows it declares** are the enumerated coverage rows the document declares,
  re-measured in its fetched bytes. Only a coverage-row key may be written in
  backticks in that column, because the gate reads every backticked token there
  as a row name and fails on one no region file carries.
