## The rule

Array items that are `{type: object, oneOf: [...]}` over members declaring properties but no `type` are Fern's named element union `{Name}Item = typing.Union[{Name}ItemZero, {Name}ItemOne]` of models (their `op`/`path` enums hoisted beneath), and the request is worked as `[{Name}ItemZero()]`. The handed-off rd-alliance document carries a second rule under this cause: an array element `allOf: [{inline properties}, $ref Parent]` hoisted out of `Parent`'s own recursive property restates `Parent`'s fields rather than subclassing it, still importing `Parent` for its forward references.
