## The rule

A query parameter whose schema is an `anyOf` of a scalar written `nullable: true` and an array of that scalar (the handed-off document's `disabled_at`) is not the one-or-many shorthand: it is the named request union `{Op}Request{Param}`, declared in the package root's `types/`, with the nullable scalar member `Optional` and the element `Optional` as written.
